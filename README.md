## 🚀 Getting Started

### Prerequisites
- Docker & Docker Compose
- Node.js v20+ / Python 3.12+

### Installation
```bash
git clone https://github.com/amezianeomar/POSTRESA.git
cd POSTRESA
docker-compose up -d
```
